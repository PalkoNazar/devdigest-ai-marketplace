# Changelog

All notable changes to `engineering-paved-path`. Versions follow [SemVer](https://semver.org):
renaming or removing a skill is a major version, since other plugins load skills by name.
Each release is tagged `engineering-paved-path--v<version>`.

## 1.0.0 — 2026-10-29

### New

- `react-best-practices`, `next-best-practices`, `react-testing-library`,
  `fastify-best-practices`, `security` skills.
- `onion-architecture` and `frontend-ui-architecture`, generalized from DevDigest's
  project-specific versions to a default layout that a project's own docs can override.
