# Changelog

All notable changes to `research-tools`. Versions follow [SemVer](https://semver.org):
a change to the agent's input or report format is a major version.
Each release is tagged `research-tools--v<version>`.

## 1.0.0 — 2026-10-29

### New

- `researcher` agent with REPO and EXTERNAL modes.
- Read-only Bash guard (`hooks/readonly-bash.mjs`) scoped to `research-tools:researcher`.
